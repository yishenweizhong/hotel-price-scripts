携程价格抓取 v1.2.1 · M 系列 Mac · macOS 13 及以上

应用就在这个文件夹里。

双击蓝色图标「携程价格抓取.app」

看到带蓝色酒店图标的文件，就是应用。若 Finder 隐藏了后缀，名字显示为「携程价格抓取」。也可以把它拖到同文件夹的 Applications（应用程序），以后从“启动台”打开。

第一次打开

  1. 双击应用，等待价格采集窗口出现。
  2. 若系统提示无法验证开发者：关闭提示，打开“系统设置 → 隐私与安全性”，找到本应用的提示，选择“仍要打开”。本版尚未通过 Apple 公证，不需要购买开发者会员。
  3. 安装并登录携程旅行桌面 App；电脑需有 Google Chrome。回到应用，点“打开”准备携程，点“登录”准备来客。
  4. 按应用提示开启携程读取所需的辅助功能、屏幕录制权限。采集时保持电脑解锁。

平时只需要四步

  1. 上传门店表：直接用已有表格，一列门店名称、一列 POI ID 就够。列名和顺序会自动识别，不需要套模板；认不准时，在预览里点选对应列。POI ID 请保留为文本。
  2. 选日期：确认开始和结束日期，点“导入并进入采集”。
  3. 开始采集：等两个平台连接成功后点“开始采集”。中途可以暂停，下次继续。
  4. 下载 Excel：选择保存位置，用 Excel 或 WPS 打开结果。

怎么看来客价格

默认快速读取预售券名称和售价，不为来客截图。标准大床、标准大床房等常见别名会匹配；大床与双床、标准与豪华不会混为一间。券名晚数不明时仅显示整券售价，不强行算单晚价。

基础券价参考未含日期加价，预约库存、早餐和渠道条件需要核对。若要核对券详情和日期规则，导入时展开“更多采集选项”，选择来客详情模式。真实平台批量表现还取决于登录状态、网络和页面；本版保留失败记录及断点。

如何关闭

关闭应用窗口，或按 ⌘ Q。应用会停止自己的采集服务，已保存结果保留在本机。再次打开后从“历史任务”继续。
