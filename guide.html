携程价格抓取 v1.3.3 · M 系列 Mac · macOS 13 及以上

先放进“应用程序”，再打开。

把蓝色图标「携程价格抓取.app」拖到 Applications

解压文件夹里，蓝色酒店图标是应用，旁边的 Applications（应用程序）是安装位置。把应用拖过去，再从“应用程序”打开，以后在这里更新和授权。

之前下载过？这次需要替换一次

先退出旧版，再把新版应用拖进“应用程序”，选择替换。名单、历史结果和来客专用窗口的登录信息保留。打开后查看左下角，必须显示 v1.3.3。若旧版仍在运行，新版会提示先关闭旧版；在下载目录打开时，会提示安装到固定位置。

后续统一从 这个固定网址下载更新。新版左下角提供“检查更新”和“固定下载页”；网页更新不会自动替换电脑里的旧应用。更新检查失败不影响本机采集。

第一次打开

  1. 从“应用程序”双击“携程价格抓取”，等待采集窗口出现。
  2. 若提示“Apple 无法验证此应用是否包含恶意软件”，选择“完成”，不要移到废纸篓。打开“系统设置 → 隐私与安全性”，在本应用的拦截提示旁选择“仍要打开”，按系统要求确认。本版尚未通过 Apple 公证，使用者不需要购买开发者会员。
  3. 安装并登录携程旅行桌面 App；电脑需有 Google Chrome。回到应用，点“打开”准备携程，点“登录”准备来客。来客需登录应用连接的 Chrome 窗口；已登录其他窗口时可在高级设置中连接已有 Chrome。
  4. 首页点“开启辅助功能”，在系统设置里打开“携程价格抓取”的开关；再点“开启屏幕录制”，打开同名开关。部分系统叫“屏幕与系统音频录制”。列表没有应用时，点“＋”从“应用程序”中添加。
  5. 授权后回到应用，会自动检查。若系统要求退出并重新打开，请照提示操作，再从“历史任务”继续。两个平台均显示可用后，“开始采集”才会启用。

已经登录，为什么还是不能开始？

首页分别显示携程和来客的连接状态。携程还会显示辅助功能、屏幕录制和窗口检查结果；缺哪项，就点对应按钮处理。两个平台都变成绿色“已连接”后，顶部会显示“可以开始采集”。

更新应用后，旧版同名权限可能失效，开关已开也会被系统拒绝。展开首页“权限已经打开，还是提示未授权？”，点“修复旧授权并重新允许”，再按系统提示授权。这会清除本应用对应的旧权限，门店表和任务保留。若系统要求 Touch ID 或密码确认，请在本机完成。请保持电脑解锁，并保留一个携程主窗口。

平时只需要四步

  1. 上传门店表：直接用已有表格，一列门店名称、一列 POI ID 就够。列名和顺序会自动识别，不需要套模板；认不准时，在预览里点选对应列。POI ID 请保留为文本。
  2. 选日期：确认开始和结束日期，点“导入并进入采集”。
  3. 开始采集：等两个平台连接成功后点“开始采集”。中途可以暂停，下次继续。
  4. 下载 Excel：选择保存位置，用 Excel 或 WPS 打开结果。

怎么看来客价格

默认快速读取预售券名称和售价，不为来客截图。标准大床、标准大床房等常见别名会匹配；大床与双床、标准与豪华不会混为一间。券名晚数不明时仅显示整券售价，不强行算单晚价。

基础券价参考未含日期加价，预约库存、早餐和渠道条件需要核对。若要核对券详情和日期规则，导入时展开“更多采集选项”，选择来客详情模式。真实平台批量表现还取决于登录状态、网络和页面；本版保留失败记录及断点。

如何关闭

关闭应用窗口，或按 ⌘ Q。应用会停止自己的采集服务，已保存结果保留在本机。再次打开后从“历史任务”继续。
