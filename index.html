常见问题

需要付费或开通 Apple 开发者会员吗？

应用本身免费，使用它不需要购买 Apple 开发者会员。网络、携程与抖音来客账号由使用者自行准备。

需要把账号密码发给别人吗？

不用。在自己的携程 App 和应用打开的专用 Chrome 窗口中登录。下载页不接收平台密码或门店数据。

下载完，应用在哪？

双击下载的 ZIP，打开解压出来的文件夹，找蓝色酒店图标“携程价格抓取.app”。Finder 可能隐藏 .app 后缀。双击图标就能打开。

必须按照模板改表格吗？

不用。一列门店名称、一列 POI ID 就够，列顺序不限。支持 poi名称[最新]、poi_id[最新]、店铺名称等常见导出列名，内容明确的无表头名单也能识别。认不准时，在应用预览里点选对应列。城市和地址可选。

携程和来客都登录了，为什么“开始采集”还是灰色？

首页逐个平台显示状态，携程还会标出辅助功能、屏幕录制和窗口检查结果。缺哪项就点对应按钮处理。更新后开关已开但仍提示未授权时，展开“权限已经打开，还是提示未授权？”，点“修复旧授权并重新允许”，按系统提示重新授权。两个平台都变为绿色“已连接”后，顶部会显示“可以开始采集”。若系统要求 Touch ID 或重启应用，请在本机照提示操作。历史任务和门店表保留。

如何停止？下次还能查看结果吗？

关闭应用窗口，或按 Command + Q。已保存的数据保留在本机；下次从“历史任务”查看或继续。

以后能直接在应用里更新吗？

v1.3.1 左下角可“检查更新”并打开这个固定下载页。发现新版后下载替换，旧包和旧应用不会自动升级。这次更新不需要重新上传已有名单；系统权限可能需要按提示重新允许。
